# Auvyren Web

Next.js 16 App Router frontend for Auvyren.

- `src/app/` — routes, layouts, metadata (server components by default)
- `src/lib/api/` — typed API client and problem-details types
- `src/lib/env.ts` — browser-safe environment access
- `src/app/globals.css` — Tailwind v4 import and Phase 0 design tokens

The final visual identity and complete component system are delivered in Phase 1.
The Phase 0 page is a technical foundation screen, not the product landing page.

## Development

From the repository root:

```bash
npm run dev:web
```

See the root [README](../../README.md) for full setup.
